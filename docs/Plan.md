# 1. Введение и цель проекта
Цель тестирования — проверить работоспособность основного функционала приложения, выявить критические дефекты перед запуском и убедиться, что пользователь может успешно работать с новостями, цитатами и информацией о приложении.
# 2. Границы приложения
- Авторизация
- Страница Main - просмотр новостей, сортировка, фильтрация
- Страница News - редактирование, создание, удаление новостей, их сортировка и фильтрация
- Страница About - информация о приложении
- Страница Love is all - просмотр цитат о хосписе
# 3. Перечень используемых инструментов
- Android Studio Flamingo | 2022.2.1 Canary 10
- Google Chrome Версия 135.0.7049.85 (Официальная сборка), (64 бит) и новее
- Git-2.47.0.2-64-bit или новее
- Allure Report 
- java v.17.0.4

Разрешение на автоматизированное тестирование

# 7. Интервальная оценка с учетом рисков в часах.
- Установка и настройка необходимого ПО – 1час
- Получение необходимых разрешений и доступов – 0,5 часа
- Выполнение сценариев работы с новостями приложения – 40 часов
- Оформление отчетной документации – 1 ч
# 8. Техники тест дизайна 
Применяются техники «Черного ящика» для оценки приложения с точки зрения конечного пользователя, а также техники, основанные на опыте, такие как:
- Анализ граничных значений для валидации полей ввода;
- Предположения об ошибках;
- Тестирование на основе чек-листов.
# 9. Сортировка тест-кейсов по степени автоматизации
Автоматизации подлежат следующие тест-кейсы:
- Авторизация пользователя;
- Создание новости;
- Редактирование новости;
- Удаление новости;
- Переход на страницы Main, News, About, Love is all.
