# Запуск автотестов:
1. Установить приложение с помощью команды "adb install app/build/outputs/apk/debug/app-debug.apk"
2. Запустить тесты из папки "app\src\androidTest\java\ru\iteco\fmhandroid\ui\tests" проекта.
