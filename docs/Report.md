# Отчет о тестировании приложения VHospice
## 1. Краткое описание
Проведено тестирование приложения В Хосписе, рассмотрены следующие сценарии:
- Авторизация
- Страница News - редактирование, создание, удаление новостей, их сортировка и фильтрация
- Страница About - информация о приложении
- Страница Love is all - просмотр цитат о хосписе
   
Для выполнения тестирования использовались следующие инструменты:
- Android Studio Flamingo | 2022.2.1 Canary 10
- Google Chrome Версия 135.0.7049.85 (Официальная сборка), (64 бит) и новее
- Git-2.47.0.2-64-bit или новее
- Allure Report 
- java v.17.0.4
 
В систему автоматизации интегрирован отчёт Allure.

## 2. Количество тест-кейсов
Всего выполнено 23 тест-кейса, при этом:
 -  для сценариев авторизации - 4 тест-кейса
 -  для сценариев перехода на страницы - 2 тест-кейса
 -  для сценариев просмотра цитат на странице Love is all  - 1 тест-кейс
 -  для сценариев создания новостей - 6 тест-кейсов
 -  для сценариев удаления новостей - 2 тест-кейсов
 -  для сценариев редактирования новостей - 6 тест-кейсов
 -  для сценариев сортировки новостей - 1 тест-кейс
 -  для сценариев фильтрации новостей - 1 тест-кейс


## 3. Процент успешных и не успешных тест-кейсов
Успешно выполнено 22 теста (96%), неуспешно - 1 (4%).
Оформленно 1 баг-репорт. 
Баг возник при попытке создать новость с прошедшим временем публикации. Ошибки не появляется, новость создается.
Ещё 6 баг-репортов оформлены по результатам ручного тестирования приложения.

## 4. Итоги автоматизации 

Был составлен план тестирования, выбраны инструменты и получены необходимые разрешения (см. Plan.md).
В систему автоматизации интегрирован отчёт Allure.

Все запланированные сценарии были реализованы. Не потребовалось использование дополнительных инструментов, получения новых доступов и разрешений.
Вся работа выполнена 1 специалистом за 100 часов вместо запланированных 48ч. 
Расхождение связано с низкой компетентностью специалиста, выполнявшего работу. Этот риск не был запланирован. 
Запланированные же риски сработали и отняли около 3 часов рабочего времени.
Выполнение UI- тестов заняло 5 минут и 50 секунд. Вручную - 20 минут.
